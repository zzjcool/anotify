## 必须实现
1. 真 binary/临时DB/动态端口/namespace/key/Node 注册握手；共享 `internal/protocol` 是唯一帧契约，不固化旧 frame 数量/snake_case/ports/sticky 协议。
2. 真实提案→accept→slot0→grant→renew/result/cancel/reaped→emit/deploy/logs/upload 链路，当前凭证/ns/lease/token/cancel 与历史 attempt 绑定阴性覆盖。
3. non-idempotent 默认、retry infra 分类、namespace pin、Node config revision、预算收缩/断连不假释放、source duplicate 原 receipt、failed target 与 prune 区分。
4. 真实上传/下载限额/hash/过期/跨域、日志 current/previous 节点错误及原文完整性、严格新库/重开/拒旧库保数据、retention0/active保护。
5. 保留 passkey/password/recovery/CLIkey/devices/VAPID/独立 notify/push/security；仅具名退役旧中央 Capability 专属断言，禁止 skip/空 suite/全局 failure whitelist。
6. socket/context/子进程/浏览器有界，timeout/失败均回收 owned process group，完整 stdout/真实 exit；不扩大原等待阈值掩盖产品缺陷。
