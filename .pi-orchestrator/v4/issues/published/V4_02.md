## 实施范围 / 所有权

- 唯一 store 例外：`internal/store/artifact_manifest.go` 的 `GetTaskArtifactDownload` 选择逻辑及直接边界测试；其余 store/schema/result/namespace/runtime/protocol/Node/前端只读。
- 契约：`G3-HTTP-SPEC-RESUME-HANDOFF.md` D3/D4、ARTIFACT-HANDOFF/A1、RESULT-WIRE-AUTH、D6。不新增全局 artifact CRUD、path query 或旧协议别名。

## 必须实现
1. Node 出站 PUT 使用冻结路径与 current NodeBearer/attempt/lease/task token 授权，真实 body/hash 校验；单件 16MiB、每 attempt 64MiB/32 项。旧凭证、撤销 namespace、过期 lease、cancel 均不得写副本/registry。
2. owned spool 目录 0700、文件 0600，临时写入校验后原子落盘；错误只清 owned temp，不读取或删除用户 workDir，不回 Node 原文件。
3. 用户登录/Bearer 先验证 namespace/task 与当前 reported result manifest 的实际引用，再下载真实托管 raw bytes、安全 basename Content-Disposition。
4. 同一授权当前 manifest 中同 SHA 多路径，选择仍 live 的真实引用；不能首 expired 遮蔽后 live。全部过期 410 `artifact_expired`，没有本 task 当前 ResultRef/跨域/仅历史或别 task 同 hash 404。不能借别 owner live bytes 复活过期引用。
5. 副本默认 7 天、Task/manifest 事实按 30 天，0 为永久，active/reference 保护与 GC 一致；离线/已清理明确真实错误，不假空成功。

## 验收标准
- [ ] 真 HTTP/registry/托管文件覆盖正确上传、body SHA 错、超额、重复、撤权、过期、cancel、失败 rollback 和权限隔离。
- [ ] 下载 bytes/SHA/Disposition 与真实文件一致；含 header 注入、路径逃逸、symlink/用户文件 fallback 阴性。

- [ ] 冻结 GC/保留期及 0 永久、active 不删除有测试；不弱化原 C3 manifest/upload 断言。
- [ ] `go vet ./internal/resultspool/... ./internal/server/...`、相同包 `go test ... -count=1`、`go test ./internal/store/... -count=1` 通过（统一 direct/sum/auto）；gofmt/diff-check 通过。
