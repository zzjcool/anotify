## 目标

1. **上传**：`PUT /v1/node/tasks/{taskId}/artifacts/{encodedPath}`（真实路径/头），NodeBearer + 当前 attempt + lease + task token 同事务授权；校验 body 实际 SHA256 与 `X-Anotify-Artifact-Path`；单件 16MiB、每 attempt 64MiB/32 项；201/200 幂等语义；旧凭证/撤销 namespace/过期 lease/cancel 一律不写副本/registry。
2. **resultspool**：中枢 owned 临时/托管目录 0700、文件 0600；流式写临时文件 → 校验 hash/size → 原子 rename 落盘；错误只清理 owned temp，不读/删用户 workDir、不回 Node 原文件；`internal/resultspool` 提供可测试的接口与真实文件测试。
3. **下载**：`GET /v1/namespaces/{namespace}/tasks/{taskId}/artifacts/{sha256}`（按 #331 已冻结的 namespace 鉴权与信封习惯）：先验证用户对该 namespace/task 的授权，再只认**当前 reported result manifest 中实际引用的 ResultRef**；返回真实托管 raw bytes，`Content-Disposition` 用安全 basename（防 header 注入/路径逃逸）。
4. **D4 选择语义**：同 SHA 多路径 mixed expiry 任一 live → 200 该 live 条目；全部 expired → 410 `artifact_expired`；无当前 ResultRef / 跨 ns / 别 task / 仅历史 attempt / unknown hash → 404；expired owner 不能借别 owner live bytes 复活。不新增 path query / 全局 artifact CRUD。
5. **保留与 GC**：副本默认 7 天、Task/manifest 事实 30 天、0 永久；active/reference 保护与 GC 一致；提供真实驱动（有界 goroutine/sweeper + 停止路径），离线/已清理返回真实错误，不假空成功。不删用户数据。
