## 改动

- **新包 `internal/resultspool`**：中枢自有托管池（root/objects/tmp 0700、文件 0600），临时写 → Sync/校验 → 同 fs 原子 rename；对象名只接受 store 铸造的 `obj_*`（白名单，禁 `..`/`/`/`\`/`.`/控制字符）；`O_NOFOLLOW` + `IsRegular` 防符号链接；错误只清 root 内 own temp。含 GC 驱动（Expire→删字节→Ack，失败不 Ack）。
- **上传** `PUT /v1/node/tasks/{taskId}/artifacts/{sha256}`：node token 定位身份；attempt/lease/attemptToken/path 取自冻结常量头；声明超限先 413；流式落草稿（16MiB 上限）；实际 sha/size 与 URL 段核对；先原子发布再登记；登记事务内重做全部授权；失败补偿零写；200 幂等。
- **下载** `GET /v1/namespaces/{ns}/tasks/{taskId}/artifacts/{sha256}`：会话鉴权 + 路径 ns 授权；只认当前 reported result 的 `ResultRef`；字节只从托管对象读（`ServeContent` + 显式 Content-Type/Length/Disposition/nosniff + 零 modtime）；缺副本/symlink → 410；永不回退节点/用户文件。
- **store 唯一例外**：`GetTaskArtifactDownload` 选择逻辑修正——同 SHA 多 path 任一 live → 取 path 排序首 live；全 expired 才 410；无当前 ResultRef/跨 ns/别 task/历史 attempt → 404。修掉“首个 expired 遮蔽后 live”的既有缺陷。
- **装配**：`serverDeps.Spool`、`App.Spool/ArtifactGC`；GC 进入 `App.background`（关停 happens-before，合并 #331 时补的缝隙）；周期配置 env。
- 新增 8 个测试文件 / 60 个 Test 函数；既有 store 产物注册/选择用例全部原样通过。

## 公开接口

- 路由：`PUT /v1/node/tasks/{taskId}/artifacts/{sha256}`；`GET /v1/namespaces/{ns}/tasks/{taskId}/artifacts/{sha256}`。
- 上传成功 201/200，body 恰 5 键 `{taskId,attempt,path,sha256,size}`；错误 `artifact_path_invalid`/`artifact_hash_mismatch`/`artifact_conflict`/`artifact_too_large`/`unauthorized`/`forbidden`/`internal`/`artifact_upload_unavailable`。
- 下载 200 原始字节 / 404 / 410 `artifact_expired` / 401 / 503。
- Config：`ANOTIFY_ARTIFACT_SPOOL_DIR`（默认 `<DB 目录>/artifacts`）、`ANOTIFY_ARTIFACT_GC_INTERVAL_SEC`（默认 300，0 禁用）。
