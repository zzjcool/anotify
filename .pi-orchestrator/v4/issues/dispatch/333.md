## 目标

1. **exact-five**：仅 `api/{resource,events,agent,ingress,auth}.yaml` 五份真实 OpenAPI（paths 写全 `/v1/...`，servers 不再补 `/v1`）；删除旧 `api/openapi.yaml`；禁止第六真源/旧文件 fallback。
2. **归属机械规则**：operation 归属键 `(method, canonical path)`；同 path 不同 method 不互相覆盖；`operationId` 全局唯一；同 method+path 禁止跨文件重复。
3. **引用**：五文件内部/cross-file 相对 `$ref` 可解析（含 `components.pathItems`）；禁 remote/绝对路径/逃逸/第六真源。
4. **handler parity**：每个真实注册 route（含裸前缀挂载内部 switch 的 method）有且仅有一份 spec operation；每个 spec operation 有真实 handler；anonymous/session/ConsoleBearer/NodeBearer 与代码中间件一致。
5. **DTO/envelope**：lightweight Resource、status 只读、camelCase、空数组 `[]`、cursor、opaque CAS、writeOnly、provenance；E1 未解析失败 Task/emit `taskId`、未知 version/digest presence 例外准确。字段双向核对（漏字段/多字段都失败）。
6. **升级 `scripts/check_contract.py` 到 v4 真实边界**：不存在的 executor/cmd/agent 引用改为 v4 等价守卫（中枢禁 exec、内容寻址、上传授权/registry 边界）；**不得禁用 guard 求绿**。
7. 新增 `scripts/check_envelope.py`（或等效 Go 契约测试）做 envelope/status/camelCase/CAS/writeOnly 机械断言。
8. 交付 operation/method/path/security inventory（给 #335），并写 `docs/v4/g3c-spec-inventory.md`。
