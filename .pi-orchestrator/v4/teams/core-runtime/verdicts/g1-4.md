## E1（emit WS）同事务权威——实际签名的契约方法

```go
// internal/store/emission.go
type EmitAuth struct {
    TaskID        string // 发起 emit 的逻辑任务
    NodeID        string // 提交方节点
    NodeTokenHash string // 节点身份令牌 sha256（明文不进 store）
    Attempt       int    // 本次执行 attempt
    LeaseID       string
    AttemptToken  string // 本次执行的一次性令牌明文（只在校验用）
    Now           int64  // 租约未过期的判定时刻（0 → Now()）
}

func (d *DB) EmitAuthorized(ctx context.Context, auth EmitAuth, rec *EmitRecord, tasks []*Task) (json.RawMessage, bool, error)
```

单事务内的顺序（不可调）：① `nodes.token_hash == auth.NodeTokenHash`；② ns 授权 `authorized(node_configs.namespaces) ∩ declared(nodes.declared_namespaces)` 覆盖任务所属 ns；③ 执行授权 `phase=running` + `task.node_id==auth.NodeID` + `attempt/lease_id` 相等 + `sha256(AttemptToken)==attempt_token_hash` + `lease_until > now` + `cancel_requested_at IS NULL`；④ **才**查 emit_id 幂等/冲突；⑤ 同事务写 emission + 子任务 + 剪枝回执。旧的 `EmitAndCreateTasks`（无授权参数）已删除，不留旁路。错误哨兵：`ErrNodeIdentityMismatch` / `ErrEmitNamespaceDenied` / `ErrLeaseMismatch` / `ErrAttemptTokenInvalid` / `ErrTaskNotRunning` / `ErrEmitIDConflict`。不持久 requestId、不存业务 seq。
