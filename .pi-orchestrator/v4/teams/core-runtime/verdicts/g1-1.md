### 实现裁决（D-I12 留白，供 IMPLEMENTATION-NOTES 收录；未落盘因为任务卡只授权两个包）

- 时间戳（`expiresAt`/`startedAt`/`finishedAt`）= RFC3339 字符串（Go `time.Time`）；文档未规定 wire 编码。
- `task.result.result.artifacts` 元素 `{path,sha256}`，对齐 `api-conventions §7.6` 的 `Task.status.result`。
- `task.cancel.reason` 第三类取字面量 `abandoned`（doc 原文「基础设施 `abandoned`」）。
- applied 文件写 canonical JSON 字节（JSON 是 YAML 1.2 子集）：protocol 必须零依赖，不能引 yaml；DTO 仅 json tag。
- artifact 的 `lifecycle/concurrency` 用 `*int` 区分「省略」与「显式 0」（`resultTtlSec:0` = 永不清理），canonical 输出仍是数字，并提供 `Effective*()` 访问器。
- protocol 只承载节点 wire 词表；§6.1 写期码归 artifact/server，避免第二份镜像。
- **实测发现并修复的脚本缺陷**：bash 只在「当前前台命令结束」或「内建 wait 被打断」时执行 trap；原写法 `wait_out=$(hc wait …)` 会让节点 cancel 的 TERM 等整段 wait 返回才生效（runner 5s 后就 KILL，等于取消时从不 interrupt 会话）。改成「hc wait 后台 + 内建 `wait`」，`TestAgentTUICancelInterrupts` 从 30s 延迟变成立即（红→绿）。
