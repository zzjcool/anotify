### 三条 major 的落点（store 域已修 / 传输仍 pending 分清）
1. **TaskInputs 漂移**：`GrantLease` 在同一 `BEGIN IMMEDIATE` 事务内读 local>node 合并值并写 attempt 快照（vars/limits/来源/revision/共享 hash）；`TaskInputs` 只读 `task_attempts` + 任务首次 pin 的 ns 快照，无快照 `ErrNoAttemptSnapshot`，**绝不回退读当前 node_configs**。→ **store 已修**；G2 取输入时机（grant 后）待接线。
2. **旧 attempt 槽无法精确回收 / 旧 ACK 烧槽或误清新槽**：新表保留每次执行的 node/instance/slot/lease/token hash；`ReapTaskAttempt` 以「当前 node token hash + taskId/attempt/leaseId/slot（+instanceId）」匹历史行，旧授权无需 active，只清旧 occupancy，重复幂等；`AckCancel` 对旧 attempt 仍 fail-closed。→ **store 已修**；`cancel.ack` 的 `leaseId/slot` 字段是 T3 delta，G2 映射前旧 ACK 只能走 `ReapTaskAttempt`。
3. **`ReclaimStaleSlots` 假 reaped**：删掉「phase != running → 清槽」；改为 `SlotObservation`（`Busy *bool` 三态 + 历史 refs + ObservedAt）；缺数组/缺 busy/未提及 slot/refs 不符一律不动；`RecoverLostLeases` 任何分支都不释放物理槽；`MarkNodeOffline` 只置 alive=0 保留 busy。→ **store 已修**。

### A3 消费对照
- accepted slot 消费：`GrantLease(...,slot,...)` 用 `bindSlotOn` 原子映射 node+slot→instance；slot 未申报/被占/超出 `limits.total`/预算已满 → `ErrSlotUnavailable`，回 pending+waiting_for_slot+有界退避、不耗 attempt；不随机挑槽。
- assignment 30s：`AssignTaskAt` 写 `assignment_expires_at=now+30`；grant 同事务校验未过期；同 assignment/节点窗口内重复 assign 幂等；过期清候选、不耗 attempt。
- `serialize`：attempt 预算、node online、取消在飞、assignment 有效性、config applied、slot 绑定全在同一事务复核。
- Hello/实例事实：`SlotObservation.Busy` 三态；`busy=false` 必须带相符 refs；`busy=true` 含 task/attempt/lease（reservation 可带 assignment/proposed，不造假 lease）；wire `concurrency` 从 store 形状移除。
- 预算缩小：不假释放存量（busy 保留），新 grant 只能在新预算内。
- 机器快照：`MachineConfigHash` 复用 `protocol.MachineConfigHash`，不含 revision/ns/token/凭证/passthrough；attempt JSON 不回显机器值/token hash，只回显 sources/revision/hash。
- GC：`DeleteExpiredTasks` 增加 `NOT EXISTS(reaped_at IS NULL)` 硬保留；active 任务永不删。
