## 问题

19 个页面共用同一套 token，所以页面读起来是"一片"而不是"若干块"——这是"不够精美"的最大单因，且是**一处改动、全站受益**。

## 范围 / 落点

- `web/tokens.css:29-33`（暗）/ `:179-183`（亮）：`--bg` / `--bg-raise` / `--surface-1/2/3`
- `web/tokens.css:34/35`（暗）、`:184/185`（亮）：`--line` / `--line-strong`
- `web/ui.css:2760-2768` `.card` 的 border/box-shadow
- 引用面（改 token 前必须知道）：`--surface-2` 在 ui.css 49 处 + pages 51 处（表头 `.data-table th` `ui.css:3039`、输入框 `.input` `ui.css:549`、卡片 hover `ui.css:2771`）
