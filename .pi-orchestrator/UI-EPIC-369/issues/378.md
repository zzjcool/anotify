## 现状（按当前代码）

| # | 事实 | 证据 |
|---|---|---|
| 1 | **403 与 500 共用同一句文案**：`请求被拒绝 HTTP {code}`，没有"无权限"分支 | `web/partials.js:2437-2480`（`status>=500 ? server_error : request_rejected`） |
| 2 | 18/19 页没有"无权限"态；唯一一处专属文案是节点页系统保留期 | `web-src/pages/nodes.html` 的 `admin_only` |
| 3 | **错误也走 toast，3.6s 自动消失**（不可持久、不可复制） | `web/partials.js:2109-2145` |
| 4 | 危险操作一律原生 `confirm()`（17 处）+ 3 处 `alert()`，**无撤销** | 见评审文档 §4.1 C7 |
| 5 | 弹层**不绑 Esc**，只切 class | `web/partials.js:2489-2512` |
| 6 | 403 时用户不知道该找谁、也不知道是权限还是 bug；500 时不知道能不能重试 | 实测：任何 4xx/5xx 页面 |

实测样例（`full/message-detail-d-dark.png`）：日志区报 `载入失败：请求被拒绝 HTTP 410` + 英文 `Task log archive is unavailable or expired`，中英混排。

## 问题

错误是产品的一部分。当前错误信息在讲 HTTP 码，用户在问"我该怎么办"。

## 范围 / 落点

- `web/partials.js:2437-2480`：`loadErrorNode` 增加 401/403/404/409/410/5xx 分支（401 跳登录、403 说权限与找谁、409 说冲突并给"重新加载"、410 说已过期）
- `web/partials.js:2109-2145`：错误 toast 改为**持久条**（手动关闭 + 复制详情）；成功仍可自动消失
- 原生 `confirm()`/`alert()` 收敛为统一危险弹层 + 「已删除 · 撤销（5s）」
- `web/partials.js:2489-2512`：`openModal` 绑 Esc

## 验收

- [ ] 403 显示"你没有权限执行这个操作" + 具体找谁（管理员/命名空间所有者）；不再出现裸 HTTP 码
- [ ] 500 显示"服务端出错" + 重试按钮；4xx 不再显示"服务端"
- [ ] 错误提示**不会自动消失**，可复制完整错误（含 requestId 若有）
- [ ] 删除类操作可撤销（或至少二次确认 + 明确后果文案），`grep -c "confirm(" web-src/pages` 为 0
- [ ] 弹层 Esc 可关（逐个弹层验证）
- [ ] e2e：新增 403 页级断言；现有错误态断言不失效
