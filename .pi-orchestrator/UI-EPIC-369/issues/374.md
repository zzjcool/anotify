## 现状（按当前代码）

工程内部字段直接印在用户界面首屏：

| 位置 | 上屏内容 |
|---|---|
| `source.html` 配置卡 | `resourceVersion（CAS 令牌）31`、`targetsResolved（布尔）`、`targets 已解析` |
| `node.html` 右栏 | `已应用哈希 sha256:<64 字符>`、`已应用产物 sha256:<64 字符>`、`已部署能力` 5 条各带 64 字符指纹 |
| `node.html` 槽位卡 | `slot 0 · 占用（运行、预留或回收中）· task=tsk_mock_2 · id=nins_mock_1` |
| `message.html` 诊断卡 | `configRevision 7`、`namespaceVarsRevision 12`、`digest sha256:<64>`，注脚 `未设置 waitingReason · nextAttemptAt · leaseExpiresAt · parentTaskId` |
| `events.html` 每行 | `事件 UID（非 deliveryId）` 与 `deliveryId` **两个 ID 并列** |
| `nodes.html` 行 | `配置版本 8` / `已应用版本 7`（漂移），但**没有任何视觉警示** |

## 问题

- 用户要判断"这个源/节点是否正常"，看到的是哈希与 CAS 令牌；
- `配置版本 ≠ 已应用版本` 是真正重要的状态，却和普通文本同样样式，漂移看不出来；
- 两个 ID 并列，用户不知道该复制哪个。

## 范围 / 落点

- `web-src/pages/source.html`（配置卡 KV）
- `web-src/pages/node.html`（配置与应用事实、槽位卡、已部署能力）
- `web-src/pages/message.html`（诊断卡字段 + 未设置注脚）
- `web-src/pages/events.html`（双 ID）
- `web-src/pages/nodes.html`（版本漂移的视觉处理）
- 若字段来自 K8s 风格 JSON：`resourceVersion` 等不要删，只收进折叠层

## 验收

- [ ] 默认视图不出现 `resourceVersion` / `sha256` / `slot id` / `deliveryId` / `configRevision`（grep 页面文本为 0）
- [ ] 上述值仍可查看：统一收进「开发者信息」折叠区（可用 `<details>`），可复制
- [ ] `配置版本 ≠ 已应用版本` 时有明确视觉警示（不是普通文本）
- [ ] 事件行只保留**一个**对外 ID（文案 `事件 ID`），另一个进折叠
- [ ] e2e：现有断言若依赖这些文本，改为断言折叠区内的值（不要把断言删掉）
