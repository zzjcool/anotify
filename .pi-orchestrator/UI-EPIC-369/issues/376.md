## 现状（按当前代码）

| 位置 | 问题 |
|---|---|
| `sources.html` 每行 | **5 个动作**：编辑 / 停用 / 删除 / 已保存源试运行 / 立即运行（后两个对非作者不可分辨） |
| `source.html` 页头 | 同样 5 个按钮，390 宽下折成 3 行（`shots/mobile/05-source-390.png`） |
| `security.html` | 同一个"添加 Passkey"有 **3 个入口**：页头「+ 本机添加」、「⇄ 在新设备添加」、空态内「+ 本机添加」；文案还教用户"点右上角「+ 本机添加」" |
| `playbooks.html` | 同一件事 3 个入口：页头「导入安装包」、空态「立即导入」、表单「保存安装包」（且页头按钮只是 `#pb-import` 锚点，点了只滚动） |
| `playbooks.html` | 空态卡 + 常驻导入表单**同时存在** |
| `keys.html` 行尾 | 只有红色文字「停用」，危险动作与正文同级、无图标 |

## 问题

同一页里出现 3~5 个"看起来都能做主任务"的按钮，用户必须读文案才能决定点哪个；空态与落地表单重复。

## 范围 / 落点

- `web-src/pages/sources.html` 行内动作区 + `source.html` `#src-actions`
- `web-src/pages/security.html` 页头两个按钮 + 空态 CTA
- `web-src/pages/playbooks.html` 页头 CTA / 空态 / 导入区
- `web-src/pages/keys.html` 行尾操作

## 验收

- [ ] 每行/每页头：**1 主 + 1 次 + «⋯» 菜单**（`已保存源试运行` 与 `立即运行` 合并或移入菜单，菜单项带一句差异说明）
- [ ] 空态只保留 **1 个** CTA，且**就地完成**（预案导入改弹层，不再是锚点跳转）
- [ ] 同一动作在同一页只出现一次（安全页 Passkey 三入口收敛为 1 主 + 1 次）
- [ ] 危险动作（删除/停用/吊销）在行尾有统一视觉语言（图标 + 危险色 + 二次确认），不与正文同级
- [ ] 390 宽下每页头部动作不超过 2 行
- [ ] e2e 定位器同步（涉及 `sources`/`security`/`playbooks` 的套件）
