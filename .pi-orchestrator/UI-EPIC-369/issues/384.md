## 问题

主内容（表格的"操作"列、链路图的下游节点、热力图的近半年）在手机上默认不可见，且 iOS 不滚动就不显示滚动条，用户不知道右边还有东西。

## 范围 / 落点

- keys 表：`keys.html:69-70`（`min-width:620px`）+ `ui.css:811`（`max-width:calc(100vw - 5rem)`）
- admin 用户表：同上模式
- 图：`ui.css:4645-4657` + `flograph.js` 的布局宽度（`contentW`）
- 热力图：`ui.css:875` + `index.html:625-668`
- 代码块：`ui.css:785`
