## 问题

暗色下占位符/弱化文字读不清；亮色下成功/失败/警告药丸读不清。这不是审美，是**信息在该主题下不可读**。

## 范围 / 落点

- `tokens.css:38`（暗 `--faint`）、亮色对应行；`tokens.css:209-219`（亮色 `--success/--error/--warn/--*-300`）
- 药丸两族：`ui.css:508-545` + `ui.css:2970-3007`
- 使用分布：`status-*` 主要在 passkey-enroll(11) / security(9) / cli-auth(6)；`badge-*` 主要在 message(11) / admin(10) / trace(10)
