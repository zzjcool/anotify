## 问题

跨页跳转时密度/圆角/字号跳变，观感像"多个团队各写了一套"。且因为没有字号/间距 token，任何统一调整都要逐处改。

## 范围 / 落点

建议**分批**（每批一个 PR，避免一次动 500 行 CSS）：

1. 药丸 → 1 套（尺寸 2 档：常规 / 紧凑）
2. Tab → 1 套（`.tab` 为基准，其余映射过去）
3. 按钮 → 去掉 `ui.css:423` 那套旧定义，`index.html:371` 补 `.btn` 基类
4. 删除重复定义（`.list-row`/`.notif-row` 合并、`modal-panel`/`code-block`/`seg-switch`/`yaml-copy` 各留一处）
5. 加 **字号刻度**（`--fs-xs/sm/base/lg/xl`）与 **间距刻度**（`--sp-1..8`）到 tokens，先只在新增/重构处使用，不做全量替换
6. `is-*` 并入 `.is-error` 单一定义（用 CSS 变量分页差异）
