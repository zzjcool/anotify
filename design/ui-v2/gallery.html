标题字体 A/B Fraunces vs Inter

结论写进 REVIEW.md「标题字体 A/B」：大标题保留衬线（品牌温度）， 但正文/列表标题一律 Inter。下面两行同字号同内容，直接对比。

A · Fraunces 600 / 30px (-0.015em) 晚上好，demo 欢迎语与 h2 主标题保留衬线：当前方案，契约 §8 已冻结。
B · Inter 600 / 28px (-0.03em) 晚上好，demo 紧字距无衬线：更「工具」、和列表 14px 同一族，但品牌辨识度下降。

给实现侧的两条提醒 readme

顶栏 h1 是「上下文标题」（15px），页面大标题是内容区的 .page-title（h2，28px）。理由与契约 §4.2/§8 的关系见 REVIEW.md「契约矛盾」小节。
折叠态不重建 DOM、不删文字节点：label 用 .side-text 收窄 + 透明， tooltip 用 ::after { content: attr(data-tip) }，e2e 取 label 文本仍然成立。
