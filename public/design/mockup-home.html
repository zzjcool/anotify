How it works

三步，完成即通知

无需改造你的 Agent。一条 Hook 上报，剩下的交给 Anotify。

01

Agent 完成工作

你的 Agent 跑完任务——代码重构、部署、测试……任何长任务结束时触发事件 Hook。

on_task_complete → POST /notify
02

Anotify 接收事件

后端用 Go 单二进制接收上报，通过 Web Push 协议加密推送，端到端保护内容。

Web Push · E2E encrypted
03

推送到你的设备

手机、桌面、网页同时弹出通知。点开直达结果详情，无需打开终端查看。

iOS · macOS · Win · Android
Why Anotify

为 私有与安全而生

没有第三方账号体系，没有云端依赖。数据完全在你手里。

🔑

Passkey 免密登录

用指纹 / Face ID 一键登录，无需记密码。基于 WebAuthn 标准，抗钓鱼。

🔒

端到端加密

Web Push 全程 E2E 加密，通知内容只有你能看到，服务端无法窥探。

📦

私有化部署

Go 单二进制 + 内嵌前端，零外部依赖。跑在自己的服务器上，数据完全自主。

🌐

全端覆盖

iOS、macOS、Windows、Android、Web 五端同时推送，一处完成全端知晓。
