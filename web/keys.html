Key 的安全实践

  • · Key 明文只在创建时展示一次，之后无法再次查看，只能重新生成
  • · 服务端仅存 argon2id 哈希，即使数据库泄露也无法还原 Key
  • · 建议每个 Agent / 环境一个 Key，泄露时只停用受影响的那一个
  • · 不要把 Key 提交进代码仓库；用环境变量或密钥管理器注入
