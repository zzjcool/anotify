Agent 連携

お使いの Agent に通知プラグインをインストールします。インストール後、プラグインがログイン認可まで案内し、タスク完了時に通知をデバイスへ自動配信します。

agent_settled イベントを監視し、タスク完了時にすべてのデバイスへ通知を自動プッシュします。skill でインストールし、プラグインがログイン認可まで案内します。

インストール
# ターミナルで実行して pi 通知 skill をインストール
pi skill install anotify

インストール後、任意の pi タスクを実行するとプラグインが自動的にログイン認可を案内します。Key の手動設定は不要です。
