Suscripciones push del navegador

Entregado vía servicios Push del sistema (APNs / FCM). Recibe aunque el navegador esté cerrado.

Recepción por conexión larga · para plugins y cualquier dispositivo

Cualquier dispositivo / plugin con una API Key de permiso notify:receive puede abrir una conexión WebSocket larga para push en tiempo real. Ideal para widgets de escritorio, daemons CLI, puentes de domótica. Funciona junto al push del navegador.

Conexión

$ wscat -c wss://api.anotify.dev/v1/stream \

-H "Authorization: Bearer ant_recv_…"

Enrutado por etiquetas · qué dispositivo recibe qué notificación

Incluye deviceTags al reportar. Solo los dispositivos con etiquetas en común (o sin etiquetas = receptores totales) la recibirán. Sin etiqueta en la notificación = difusión a todos los dispositivos activos; sin etiqueta en el dispositivo = recibe todo.
