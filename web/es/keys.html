Buenas prácticas de seguridad de la Key

  • · El texto plano de la Key se muestra una sola vez al crearla; no puede volver a verse, solo regenerarse
  • · El servidor solo guarda el hash argon2id; ni una fuga de DB puede recuperar la Key
  • · Usa una Key por Agent / entorno; revoca solo la afectada si hay fuga
  • · Nunca subas Keys al control de versiones; inyéctalas con vars de entorno o un gestor de secretos
