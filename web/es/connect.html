Instala un plugin de notificación para tu Agent. Tras la instalación, el plugin te guía por la autorización de inicio de sesión y entrega notificaciones a tus dispositivos al terminar las tareas.

Disponible

Escucha el evento agent_settled y envía notificaciones a todos tus dispositivos al terminar una tarea. Se instala vía skill y el plugin te guía por la autorización de inicio de sesión.

Instalar
# Ejecuta en tu terminal para instalar el skill de notificación de pi
pi skill install anotify

Tras instalar, ejecuta cualquier tarea de pi: el plugin te guía por la autorización, sin configurar Key manualmente.
