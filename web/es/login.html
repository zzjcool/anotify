Sin contraseñas · Acceso con Passkey en un toque

Toca el botón para entrar con un Passkey (Face ID / huella / llave de dispositivo) en este equipo. No necesitas nombre de usuario.

Huella / Face ID / llave · Resistente a phishing

2–32 caracteres: letras, dígitos, _ -. (sin símbolos en los extremos)

Al registrarte se genera un conjunto de códigos de recuperación de un solo uso— úsalos para recuperar el acceso si cambias de dispositivo o pierdes todos los Passkeys. Guárdalos a salvo.

Usuarios de iOS: para recibir notificaciones push, abre primero este sitio en Safari, toca Compartir → Añadir a pantalla de inicio y luego ábrelo desde el icono e inicia sesión.
